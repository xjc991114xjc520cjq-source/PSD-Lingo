# 0.3.27 Illustrator 首版验收

日期：2026-10-28。原生执行环境：Windows，Adobe Illustrator 29.4.0。

使用自行创建的中文 AI 测试原稿，包含背景图形、普通点文字和独立区域文字。任务只处理测试文件或磁盘副本。

通过项目：

- 原稿导入、文字元数据读取、原稿预览和隐藏已绑定原文后的背景预览。
- 英文及日文分别输出 AI，并用 Illustrator 重新打开读取；目标文字、实际字体、字号和字距正确，文字保持可编辑。
- 区域文字和点文字的可见文字边界位置与目标位置偏差小于 0.1 点。
- 跳过的文字仍为原文；点文字改字测试中，非文字路径边界、填充颜色、描边、路径节点数、图层数和画板数均与源文件一致。
- 源文件 SHA-256 在测试前后保持一致；读取本机 Illustrator 字体目录成功（测试机器 712 款，数量因设备而异）。
- 412 项自动化测试通过，renderer 构建通过。

本轮原生修正：逐字样式检查后不再复用可能失效的 Illustrator 字体对象，先保存必要的标量参数；串接文字用 story 中的文字框数量判断，避免单一区域文字被 nextFrame 返回值误判；文字定位使用临时副本轮廓测量实际墨迹边界，输出文字本身不转曲。

验收范围为上述合成样本。未将所有客户 AI 文件、复杂文字、链接资源、色彩配置或所有 Illustrator 版本视为已验证。首版限制参见《AI支持说明.md》。
