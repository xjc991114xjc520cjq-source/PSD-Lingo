# 成品检查、完整设计审验与独立高级审验

用户要求：优化审验动作本身；仅检查已导出图片，不关联、哈希或重新渲染源工程；默认成品纠错，任务前可勾选完整设计审验，左侧可独立高级审图。不得以字符框判美感，不为可读背景装饰误中止。

## 实现

review-profile 合约：delivery（默认）／advanced。主进程验证、AgentTask 持久化、工作记录草稿／续做、助手上下文及 export_files 到普通／画板审验均传递用户选择。独立 image-audit 强制 advanced，主进程限制仅 audit_images、attachments、list_folder；不能利用纯审图免输出目录来执行制作或写入工程。

高级入口：左侧“高级审验”（openAdvancedAudit；共享导航 advanced-review）。JPG／PNG 多选、拖入、移除、要求和应有文案、当前本机模型选择；使用现有本机 Codex app-server 会话与 AnalysisExchange。无 API 回退，无第二模型。问题按图给出位置描述、根因、动作和验收标准；通过项折叠；工作记录保留报告、需求和模式，结果页可直接打开报告。无批准文案不捏造缺失内容。

最终图片：currentOnly，不索取source图；Photoshop／Illustrator deliveryVisual仅校验实际JPG收据，不再哈希工程。导出制作阶段保存重开校验仍保留；审验结束不重复执行整工程 verify。保留导出JPG原字节及实际尺寸；独立PNG保留原图并验证结构，不套缩略图的2048尺寸和1MiB限制。

效率：最多6页窗口，并按传输图片数量／体积拆小批；大图不拒绝。边准备边审、逐页独立结论。紧凑状态映射保留6项文字／视觉检查、4项设计判断及适用技能覆盖，仅一句总体证据和去重修改清单；最终不自动追加6张裁图重审。缓存改为摘要键，至少256页，身份包括当前图、批准文案、模式、模型与规则；失败不会缓存成通过。
