# 多语言关联排版操作守则

版本：2026-11-05。适用于现有多语言替换模块。用户六项纠正优先于此前案例排版；技术检查通过不代表视觉验收通过。

## 输入、权限和匹配

- 原始PSD/PSB/AI为内容和配图基准；本例以用户提供原版AI、英文AI和明确纠正作为学习依据，表格为辅助信息。
- 已学习方案必须保存schema版本、来源、原稿SHA-256、画板及文字身份、目标文案、字形样式、关系对象和每项许可。只接受完全匹配的原稿；不通过文件名推断同稿。
- 本机方案为数据，不是任意脚本。只支持列明的关系类型；未知字段含义不作为执行指令。不得从外部方案执行命令或网络请求。
- 另存新文件，禁止覆盖原稿。复制源文件到其同级临时位置以保持相对链接，结束清理临时副本，恢复用户先前活动文档。
- 客户文字、图片、案例方案不随公共安装包发布。

## 六类硬性操作规则

1. **价格层级和容器**：右侧到手价使用高亮，金额比标签更显著；左侧原价降低层级。本例容器宽度按原价38%、到手价62%分配，标签与金额间隔6pt，内部至少4pt。这个比例是本例规则，不是所有作品通用比例。各组以实际可见字形的合并范围为整体，在各自容器左右、上下居中；两种字号的文字可独立按字形中心对齐。不得把标签与金额分别拉到容器两端。
2. **参数间分割线**：使用两侧完整参数块（数值、单位、说明）的墨迹范围；横向定位为两块可见边缘间隙的中点，纵向定位为两块视觉中心的平均位置。保留原线高度，不改变无关装饰线。
3. **行首圆点/方点**：保留原标记到原文字可见左边缘的水平间隔；译文换行后，标记锚定第一行，不按整段中心定位。保持标记大小和形状，不能覆盖文字。
4. **整体位移联动**：数值与说明下移时，关联分割线根据新位置重新计算；不得停留在旧坐标。0.28ms和0.001mm必须执行此项。
5. **标识与副标题**：按标识真实矢量轮廓与副标题墨迹测量。本例至少12pt；不足则向下移动副标题。若容器余量不足，按规则缩小/重排并审查，不能把问题推给下一行或容器边框。
6. **同类同步**：AIR与NEO主海报、同级标签和对应组件使用相同规则；每个实例分别测量、分别校验，不用“修好一个页面”代替全部实例审查。

## 图形保护

产品图、背景、蒙版及无关路径锁定。明确识别的价格高亮、行首标记和分割线可作为文字依赖对象调整，必须写入有限白名单，保存源对象点位、样式及身份。禁止更改裁切路径。未授权路径的点位、填充、描边、透明度，以及所有图片对象的路径/矩阵/范围应保持。

渐变和混合样式保留为可编辑原生对象；不能用文字栅格化规避排版。原生字体对象包含可变字体实例时，应复用源稿已存在的相同字体样式；不得因实例名不能直接查询而自动替换字体。

## 执行与验收

- 方案执行输入只包含原稿和本机方案；独立记录输入指纹，不得暗中再次打开英文参考。
- 按已定位的源文字集合写入；保持未选画板和画板外对象，明确本次导出范围。
- 显示当前画板、阶段和完成数。分析与执行状态分开，不得显示超出总数的进度。
- 几何硬验收：价格合并墨迹中心与容器中心误差≤0.1pt；标签金额无重叠且间距受限；分割线双轴中心误差≤0.1pt；标记位于第一行前且垂直对齐；标识留白符合方案。
- 源稿和未授权图形保护检查失败即停止；错误包括画板名称和对象/关系标识。
- 保存后独立重开检查文字内容、字体、多段样式、位置与路径；导出JPG使用保存后的成果，不复用未经修订的旧图。
- 最终渲染必须检查价格、圆点、分割线和标识间距。记录“程序技术检查”“代理画面审阅”“用户视觉验收”三种状态，禁止混淆。
- 失败必须保留原因、修复及新证据，旧失败不覆盖。未支持的复杂区域文字、旋转、路径文字、未知形状等停止或转人工确认，不能静默改变外观。

## 软件操作

1. 在工作台导入原版AI，打开原有“多语言”对话框。
2. 展开“复用本机已学习的多语言排版方案（AI）”。首次点击“导入排版方案 JSON”，选择本例提供的本机方案；之后从已保存方案列表载入。
3. 核对画板数、目标文字数和关联调整清单。指纹不匹配时请重新分析，不要改名绕过。
4. 默认勾选“保存重开审查并导出JPG”；点击“另存关系排版副本”，确认译文和规则，选择新的输出文件夹。
5. 查看新AI、JPG及“多语言执行记录.json”。用户在确认渲染结果后才能把方案标记为视觉验收通过。

## 跨作品推广门槛

同稿方案回放不是跨作品自主设计。其他作品必须先建立关系候选、确定父组/语义/容器归属、置信度和用户确认，才能调用同一关系执行器。模糊候选不操作，提供说明。新语言、新构图、新格式分别测试。PSD智能对象路线、任意作品关系自动发现与在线AI自主决策不因本次实现而自动宣称完成。
