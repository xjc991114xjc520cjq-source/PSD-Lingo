## 本轮发现和修复

| 问题与触发场景 | 根因与改动 | 必要保护 |
| --- | --- | --- |
| Adobe 已提交脚本但无完整结果，助手可能继续另一引擎或重试 | `uncertain`、中断类型在主进程、renderer、助手 RPC 和原生调度之间丢失；新增允许字段的错误封装，并识别 PS 缺回执及结果数量不符 | 不明写入立即停止；已有副本保留；先核对文件，不重复改字 |
| 只导出一份文件，另一份未保存修改被当作完成 | 导出状态与待可视核验集合按整任务清除；现在使用软件返回的逐文件范围 | 所选范围以外的修改仍待保存核验 |
| 两份文件一份失败，单独修复它后仍显示整批失败 | 逐文件成功项被整批失败牵连；现在保存逐文件审验结果，重试仅替换对应状态 | 未修复文件仍然失败，不能靠成功子集掩盖 |
| 分别导出的多份文件，结束页只算最后一次 | 最后一次结果覆盖此前交付；现在合并各文件最新结果 | 不沿用旧输出的交付哈希或旧 JPG 证明 |
| 审验批次中一页提前返回，整批一直等 | 准备阶段只有发起分析的页面才释放等待；现在所有准备分支 finally 结算 | 页码对应保持；模型和取消错误传回所有等待者 |
| 普通 PSD/PSB 最后还在看工作区预览 | 普通路径缺真实最终图交付契约；新增原生保存前快照、重开比对、目标 JPG、解码/范围/哈希检查 | 图缺失或失效不能拿工作区图代替 |
| 制作代表板后，继续整批仍逐个搬整板 | 已有原生阶段文档未用于续做；现在校验完整的已完成清单和哈希后复制阶段文档续做 | 来源、计划、模板或副本变化即失效；清单不全回退既有安全路径 |
| 进度更新反复发送完整对话、重复写工作记录 | 未区分语义变化与纯进度；纯进度发送增量，工作记录进度写盘最多每秒一次 | 终态完整保存；缺基线时重新获取完整状态 |
| 本机直连仍构造无人使用的巨大旧提示词 | 提示词参数被提前读取；改为懒求值，直连分支先选择 | 不删除同会话历史或中途要求；不声称控制模型缓存命中率 |
| 大计划被旧参数字符串长度拒绝 | 旧协议存在额外字符数门槛；移除该门槛，保留结构与工具参数校验 | 合法计划可进入；非对象参数和非法操作仍拒绝 |
| 进行中重新附加同一路径新版，保留了旧身份 | 活跃任务附件追加未按规范化路径替换；与后续追问统一 | 新版必须重新注册核验；不直接沿用旧哈希 |
| 用户中途补充后仍卡在旧问题 | 普通未答问题阻止模型重新理解补充；新增重新评估标记 | 未答事项不自动批准；产品/缩放确认不得跳过 |
| 120 次操作直接成为任务失败 | 执行计数被当成终止错误；改为保留会话和成果的暂停检查点 | 用户点击继续后执行剩余部分，不重发历史和重复写入 |
| 暂停、终止或补充导致过期结果被永久计为操作错误 | 统一显式中断类型 | 原生不明写入不归入普通中断；真实冲突和导出失败仍阻止完成 |

## 从真实制作顺序检查规则

| 阶段 | 应执行的顺序 | 可以继续、跳过或局部恢复 | 必须暂停或阻止的条件 |
| --- | --- | --- | --- |
| 开始 | 输出目录、任务范围、当前附件身份先核对；独立任务清空旧工作区 | 目录附件只注册路径，按实际需要读取 | 缺输出位置、无权写、旧任务对象混入 |
| 读取与对应 | 明确活动页，读取产品/字段来源，对应原生画板 | 表格多余行、原稿多余板在确认界面选择跳过；安全候选预选但须用户确认 | 型号/配色/轴体歧义、资料变化、批准失效 |
| 制作计划 | 按板路由有/无赠品模板，明确旧块范围、价格角色和空项处理 | 已批准的空项删除重排；无替换模板时原位改字 | 原稿身份变更、删除范围不明、漏字段、未经批准缩放 |
| 修改 | 复用模板扫描、已确认映射和同任务结果；先代表再续剩余板 | 对明确变化的板或字段局部失效与重做 | 已提交但回执不明、源文件变化、写入失败 |
| 中途沟通 | 问题映射到当前蒙版；补充保留原目标和已有回答 | 普通旧问题可由模型结合新说明重评估；可暂停继续 | 不能代用户答必答问题、不能把暂停视为成功写入 |
| 保存与导图 | 原生副本保存→重开检查→实际目标 JPG→核验交付来源 | 有原生副本但导图失败，保留副本并说明阶段；局部成功可保留 | 原文/字体/位置变化、图缺失或损坏、目标范围不符 |
| 设计审验 | 用同一最终 JPG 看整页及必要细节；集中给出修正清单 | 信息不足时补同一 JPG 细节；不无依据反复审同图 | 真实设计缺陷和批准文案缺失仍不通过；原稿已有图案不能被当作新增缺陷 |
| 收尾/恢复 | 按各文件最新交付结果汇总，过程错误折叠留档 | 历史失败恢复和重新运行有可见界面、关联记录；附件变化单独报出 | 不能让未导出文件被别的文件成功覆盖；恢复不盲目重放不明写入 |

规则选择：文案来源、原稿保护、用户决定、写入回执和交付真实性必须严格。资料发现、明确跳过、空项处理、旧问题重评估、部分成功和阶段恢复要允许正常继续。学习记录仍是支线，不增加主线成功门槛。

## 性能与资源

- 普通 PS 最终审验只制作一次合并证明底图，再逐目标板裁切导图；不为每个板反复合并完整图层文档。发送的审验证据可缩至最长边 2400，不缩改原生可编辑文件。
- 模板阶段文档续做小样耗时 34.499 秒；它证明避免重复搬运，不能推算客户九板或数 GB 工程的固定加速比例。
- 500 KB 历史的 100 次纯进度更新测试没有重复传历史；终态保留完整记录。语义事件与任务原始存档仍需保存，不承诺零磁盘开销。
- 最后核对依赖最近真实工具结果；不再无条件追加一次完整工作区读取。变化或缺证据时仍允许必要读取。
- 原生调用、解析、文件哈希与实际审图都有成本。已有副本的复核不会自动再次修改整批。哈希核对不能为减少耗时而取消。
- 本轮外部模型请求为 0，因此无新增外部模型计费；无法从本轮推算生产 token 降幅或保证缓存命中。

## Adobe 通信故障与恢复证据

一次最终原生复测中 Illustrator 返回 `RPC_E_SERVERFAULT / 0x80010105`：副本已保存，无 JPG；接着只读预检也失败。此失败保留在 `native-final/error.txt`，不能称原稿损坏或已完成。

用户关闭 Illustrator 后，后台重新启动并只读打开已有副本，核对 `Final label`，补导 JPG；已保存文件哈希不变，没有再次改字。随后全新的 PSD/PSB/AI 小样和真实助手入口串联测试均通过。该结果证明恢复路径可行，不证明 Adobe COM 服务本身永不异常。

用户本轮明确授权：以后类似接口失效可自行重启 Adobe 后继续。此授权不等于允许丢弃用户未保存的原稿，后续仍须保护文档与已有副本，不直接重放不明执行。

## 与直接 Codex 的能力边界

软件正式助手继续使用本机 Codex 和所选模型，保留本机会话、图片交接、提问、补充、暂停及软件业务工具。它通过业务接口执行并接受同一套原稿与批准校验，不走独立 API 代替本机 Codex。

它不会自动获得桌面 Codex 的任意 shell、任意文件访问或所有第三方插件工具。设计技能通过当前软件已配置的审验契约、指导资料和图像交接使用；不能把列出技能名当作外部插件已执行。路径文字、特殊旋转变换、某些原生对象等未实现能力仍应准确报告或走已验证的专用路径，不能猜参数硬写。

当前测试覆盖接口通信、业务执行及审验来源，不承诺任意客户文件一次成稿，也不能证明模型一次看全所有审美问题。本轮未新增真实模型客户整稿审验；复杂嵌套和混合样式依赖已有专用原生引擎，本轮新增普通 PS 快照不能冒称穷尽所有字符样式。
