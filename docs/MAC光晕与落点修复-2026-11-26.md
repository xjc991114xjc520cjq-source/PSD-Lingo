# Mac 光晕与 Logo 落点修复

候选6性能优化移除了光晕边缘蒙版，用户反馈出现方块边缘。本次恢复椭圆柔边蒙版和50%圆角，保留有限画布及浏览器原生动画播放。

Logo原先仅按容器中心和宽度缩放，SVG图形与侧栏图片的实际裁切不同，且目的地坐标只在创建时采集。现在飞行后段交接到侧栏Logo的同图、同尺寸、同裁切副本；字体就绪、窗口缩放及启动遮罩交接时更新目的地，动画结束清理监听。另修正后段动画向前填充覆盖入场动画的问题。

## 验证

- Mac DPR2，1440与1080宽窗口、动画途中缩放：2950毫秒的落地副本与侧栏Logo的x/y/宽/高完全一致（断言容差0.25 CSS像素），图片宽40像素，原飞行Logo透明、副本不透明。
- Windows同两档窗口及途中缩放检查通过。
- 已查看Mac600毫秒光晕截图及2950毫秒落地截图，光晕为柔边椭圆，收尾Logo贴合侧栏，没有叠加错位。
- Mac首次绘制交接、失败回退、减少动态效果通过；三次性能重播最大间隔17.7毫秒，无超过34毫秒间隔。源码初次加载仍有一次约116.7毫秒间隔，不能声称冷启动完全无掉帧。
- 候选7实际包通过深度完整性签名、DMG校验与LaunchServices启动/动画结束检查；公开发布、Apple公证和用户覆盖安装后的体感未验收。
- 无外部模型、Adobe、真实账号数据调用；没有结束或修改用户当前安装的软件。
