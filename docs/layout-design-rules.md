# 多语言详情页排版设计约定

适用于 PSD-Lingo 的自动适配、Codex 排版建议、人工复核及学习样本。规则指导现有详情页的文字重排，不重新设计产品图像。

## 设计目标与依据

依据本机 Canvas Design 的空间、层级、留白及精细复核方法、Frontend Design 的内容特征、字体层级、结构表达和二次审视方法，以及 UI UX Pro Max 的字号层级、可读行长和行距建议。这里取用设计原则，不执行这些技能中与本项目要求冲突的换字体、删文案、另加装饰等建议，也不将网页的默认字号和像素间距硬套到 PSD。

LUMA 的视觉主题是柔光与日常秩序：灯具及场景是主角，胶囊承担章节导航，标题建立阅读入口，说明与功能标签提供第二层信息。精细处理现有对齐、容器及文字关系，不靠增加装饰掩盖问题。其他项目应先识别其原有主题与阅读结构，不照搬 LUMA 配色、字号或比例。

## 内容和操作边界

- 目标文案以已绑定文档为依据；若用户直接编辑过，则以用户确认内容为依据。不翻译、不改写、不省略、不添加省略号，不以改变内容解决空间问题。
- 保留原字体及用户已选字体。缺字或缺字体应指出具体问题并请用户选择；不能悄悄更换字体、字重或拉伸字形。
- 原稿、用户已确认的替换排版、源文件校验信息分别保留。自动调整支持撤回；手动确认的字号、位置、拉伸及容器编辑不能在切换语言、重开项目或导出时被重新覆盖。
- 默认只改文字。独立可编辑形状在用户允许后可以调整；位图中的产品、图案及容器不能当作独立矩形移动。圆角形状调整宽高时保留圆角像素值，除非用户要求改变圆角。

## 三阶段比较

每次排版建议及可采纳的学习样本，应关联同一源文件、文案版本和以下三种状态；不得只保存最后一张效果图。

| 状态 | 必须保留 | 用途 |
| --- | --- | --- |
| 原稿 | 原始可见图像、文字、字形区域、字体、字号、图层和容器关系 | 判断原设计的阅读层级、对齐、节奏和原有缺陷 |
| 仅替换文案 | 使用目标文案但尚未进行本轮排版调整的图像及布局参数 | 显示语言长度变化导致的真实问题，区分原稿缺陷与替换缺陷 |
| 最终调整 | 用户或自动排版后的图像、参数、修改原因和验证结果 | 评估是否改善，以及哪些变化可以学习 |

如果不能可靠重建某个阶段，明确标记缺失，不伪造比较图或声称已看过。学习记录的完整性提交条件由软件当前导出结算规则控制；不能把每次未完成拖动直接认定为完成样本。

## 可量化的排版约束

以下约束用于发现明显问题。阈值是依据源设计比例推导的检查起点，不是所有项目的固定样式。

1. **区域边界**：文字可见字形必须位于画布内。文字框、字形墨迹范围及段落可用区域要区分；点文字的紧致字形框不是整段文案唯一可用空间。保留真实原始框供源 PSD 校验。
2. **容器内边距**：确认文字与容器关系后，按文字墨迹范围测量四侧间距。居中胶囊的左右、上下留白分别均衡，不能以左对齐的段落属性代替容器居中。无法从原稿推断时可从 `max(12 px, 0.6 × 字号)` 的水平留白、`max(8 px, 0.25 × 字号)` 的垂直留白开始，再按画布比例及实际图像复核。
3. **对齐与成组**：沿用原稿清晰的左边线、中心线及卡片中心。相关标题、说明视为一组；相似功能标签共用字号及对齐规则。禁止逐层独立缩小后形成大小不一、基线不齐的同级标签。
4. **主次层级**：保留源设计的标题与说明字号比例、字重及颜色关系。空间不足时先寻找安全可用区域和合理换行，再在允许范围内调整字号；不能将主标题缩得接近说明字号。只有用户授权时才改变字距、行距或字形比例。
5. **行与段的节奏**：使用目标语言合法断行点，不拆开不可分词或留下明显不必要的孤词。比较换行方案的行长平衡、总高度及层级，不仅选择第一个未溢出的方案。不要靠行距压缩让字形互相接触。
6. **相邻避让**：每次字号、换行、位置或容器变化后，重新检查同组说明、附近文字及形状。上下文字间隔至少保留原有合理间隔；源稿间隔失效时，可从 `max(12 px, 0.3 × 邻近说明字号)` 开始检查。标题变两行后不能压住原位副标题。
7. **范围扩展**：只在明确无冲突的可用区域扩展文字或容器；必须检查同级卡片边界、相邻图层、画布边界及用户保护区域。不能仅凭“下一条文字不在这里”就断言位图产品图为空白。
8. **圆角与形状**：矩形容器保持独立可编辑身份，伸长不按比例放大圆角。宽高不足以容纳圆角时应按真实形状约束处理并提示，不能生成无效形状。

LUMA 精修原稿的参考是 1080 × 4320 三屏、72 px 主左边线、260 × 60 px 胶囊和 26 px 标签；中文三个胶囊的左右留白约为 38/37、50/50、50/50 px。英语变长后应重新居中，必要时在允许范围内延长胶囊。这些数值仅用于该测试项目回归，不进入通用项目的硬编码。

## 必须看图判断的设计事项

几何检查通过只说明未触发已知约束，不能宣称“符合视觉美感”或“设计已完成”。还需观察三阶段的实际图像，判断：

- 产品主体、灯光、背景图案、人物或手部是否被新文字挡住；不能只读取图层包围框猜测视觉主体。
- 阅读顺序是否仍然清楚，标题是否抢过产品主体，说明是否过弱或过密。
- 同组内距是否小于组间距，三屏之间的留白、重复元素和节奏是否连贯。
- 断行是否自然，视觉重心是否偏移，胶囊是否像“文字放在形状里”而不是文字贴着形状边缘。
- 目标语言字体是否真实可读，有无缺字、字体替换、异常字形或低对比度。

未提供图像给 Codex、图像无法读取或模型不支持视觉时，明确返回“已进行结构排版检查，尚未进行图像审美复核”。可以给出受限的结构建议，不能虚构已经看见画面、已经避开产品主体或已经达到设计师审美标准。

## 0.3.16 的实际执行能力

- **自动适配排版**：使用本机字体实测及容器、邻近文字约束，保留原字体和全文。这是确定性的本地排版，不冒充调用 Codex。
- **AI 设计排版**：使用用户已选择的 API 或本地 Codex 通道，附带全部可见文字的原始/当前几何信息、目标文案、同组信息和明确的容器关系，为当前文字提出排版方案。跳过和不支持的文字仍作为不可更改的避让对象。
- 背景及排版渲染已就绪时，附上当前文字周围的真实预览裁片及其 PSD 坐标，供模型结合图像分析。API 使用视觉输入；本地 Codex 使用受限临时 PNG 图像附件，任务结束后清理。当前附图是调整前的实际预览，不是尚未应用的最终方案，也不保证覆盖整套长详情页。
- 预览未就绪时仅提供结构上下文并明确提示。若已提供图片但服务商或所选模型不支持视觉，保留原布局并报告错误，不偷偷去掉图片后谎称完成视觉分析。
- AI 方案不会直接覆盖原稿；软件先检查返回字段、字号/间距范围和画布边界，再使用本机字体测量、相邻文字避让及明确容器内边距校验。通过后仅应用当前文字，支持 Ctrl+Z。等待期间改过文案或布局的旧建议不会覆盖新操作。
- 没有自动进行模型的第二轮最终图像复核；应用后的实际效果由预览供用户确认。三阶段学习资料仍由现有本机记录与成功 PSD 导出结算流程保存；此轮未开通云端学习上传。

## 建议的候选和验证流程

1. 读取原稿和用户已确认布局，识别标签、主标题、说明及同级重复项；含糊关系保留给用户确认。
2. 对照仅替换状态，列出具体问题：如“标签右内边距不足”“标题第二行压住说明”，不要只报“无法适配”。
3. 优先比较保持字号的安全区域扩展、合法换行、容器内重新对齐；再比较允许的字号或容器调整。兼顾全文、层级、同级一致性和改动量，不以单一填满率排序。
4. 输出可解释的修改建议或在已授权范围内执行，并保留原值与撤回能力。不确定的主体遮挡、容器关系或字体问题单独列为待确认。
5. 最终同时检查图像、布局参数及源文件对应关系。保存并重新打开项目、切换批量语言后重验；导出的 PSD/PSB 按用户确认预览执行，不回退到原紧致字形框再次适配。

验证报告区分“结构约束通过”“图像已复核”“Photoshop 实际导出已验证”。只完成解析、浏览器预览或单元测试时，不填写后两项为通过。
