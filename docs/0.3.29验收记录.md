# 0.3.29 本机验收

环境：Windows、Photoshop 2025 26.11、Electron 35。使用自建样本，无用户活动文档。

- Node 回归测试：419 / 419 通过。
- 原生文件：多画板相对位置匹配、共享智能对象隔离、两层嵌套、链接对象编辑、PSD/PSB 保存重开；源文件和链接素材哈希一致。用户取消不提交，已有输出文件失败后仍保留。
- Electron 原生流程：试改一处、自动列候选、勾选批量、撤销／重做；导出后重新读取的一级合成像素与确认预览一致。
- 完整软件：没有一级文字层的 PSB 导入、真实“保存项目／打开项目”路径、替换规则恢复、再次深度解析恢复原生预览，无渲染异常。
- 1500 和 1100 像素窗口检查。下拉菜单沿用软件现有主题与键盘操作。视口支持显示全图、居中与 Alt 滚轮缩放。
- 修复原生元数据脚本的嵌套条件表达式误判，8 位 PSB 能正确识别。

自动测试和原生样本不能代替所有客户文件的最终视觉审阅。混合字符样式、缺字体、隐藏锁定层及非 PSD/PSB 智能对象内容列为不可处理；版式差异和同位置多候选需人工确认。
