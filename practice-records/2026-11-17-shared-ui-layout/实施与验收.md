# 共用页面布局修复与验收

用户反馈：各页存在标题贴边、步骤数字挤压等基础布局错误。沿用现有视觉风格，修复共用几何规则，不改变制作流程、助手路由或业务参数。

根因：旧工作台、Sparkit 外观和桌面外观三套 CSS 叠加；固定高度与无内边距覆盖了新圆角外框；数字继承圆形背景却允许横向压缩。部分窗口仍使用旧的侧栏偏移；助手图标额外右边距挤压了标签。批量窗口半透明背景还让底层文字透出。

实现：统一标题安全留白、导航行高与按钮换行；步骤数字固定 22×22 并禁止收缩；侧栏标签不拆行并允许整体滚动；工作区弹窗随可用宽高缩放、采用不透明底色；工作记录对齐当前侧栏，并允许标题及筛选控件换行；小尺寸空状态保证内容能从顶部滚动查看。
