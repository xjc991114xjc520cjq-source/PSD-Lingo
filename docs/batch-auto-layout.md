# 多语言自动排版流程

批量执行时，软件先逐语言准备独立工作区，完成本地适配与可选 AI 设计，再开始生成 PSD/PSB，无需先逐份打开画布并点击排版。模板文字框溢出不会直接排除语言，应交给适配器检查容器、留白、换行和字号。

已保存的人工确认排版直接保留；自动完成的语言也保留独立计划，可随时进入“预览并调整此语言”。重新执行复用已完成计划。修改文案对应方式会清除独立计划并重新计算。

“使用 AI 优化全部语言排版”默认开启。关闭后仍进行本地适配；没有 AI 凭据时由适配器明确说明回退到本地。每种语言的检查提示独立显示，原稿读取或排版失败不会让其他语言丢失排版结果。

在排版阶段点击停止，当前分析返回后丢弃该语言结果，并且整轮不开始导出；此前完成的语言计划保留以供预览。已进入生成阶段则沿用现有安全停止流程。

`autoLayoutBatch` 不改动主项目，接受 `autoLayoutLanguage({prepared,document,template,useAi,isCancelled,onProgress})` 适配器，返回 `{plan,layers,issues?,cancelled?}`。没有有效导出计划的语言不会自动进入生成队列。
