# 排版学习范围

学习对象仅为文字位置、区域、字号、字体样式、字距、行距、换行和容器几何；不学习文案改写。

- 单独修改文字内容，即使触发了自动缩字或重新换行，也不会产生排版样本。
- 同一段操作同时修改文案和排版时，以当前确认文案重新计算调整前和仅替换基线。调整前、替换基线、最终排版采用同一目标文案；原稿保留作为视觉参考。
- 内容不同的旧截图不能作为排版调整前对照；无法重算的旧客户端测量会去除旧换行文字和该截图。
- 文案及原稿文字可作为语言、长度、测量与渲染上下文保存；记录标明 `learningScope: layout-only`、`textRole: measurement-context`。操作清单只包含发生排版变化的图层和容器，不包含改写差异或改写建议。
- 暂存与提交两侧均检查真实排版变化。只有产生匹配 PSD/PSB 且整次生成没有大面积失败后，才允许将草稿提交为参考样本。撤销不采集正向成果。
- 本轮不会重写、删除旧样本，也不会开启云端上传。

这里只采集本地参考资料，不会训练模型权重或自动套用历史文字内容。
