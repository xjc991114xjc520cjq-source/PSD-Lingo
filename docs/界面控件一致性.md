# 界面控件一致性

单选下拉框统一使用 `renderer/select-controls.js` 与 `renderer/style.css` 中的共享样式。主窗口初始化一次，静态和后续动态生成的 select 都自动接入，不逐个编写临时菜单。

- 收起态遵循主程序的字体、绿色焦点、边框、圆角和禁用态；不得直接暴露系统默认黑色下拉框。
- 展开态使用共享菜单、浅绿色选中背景和勾选标识，不出现系统默认蓝色选项。
- 保留原 select 的 value、disabled、options、input／change 事件及已有设置持久化逻辑。
- 鼠标、键盘、外部关闭、模态窗口层级、动态刷新和小窗口边界必须同时验证。
- 后续主题变更修改共享组件与 CSS，禁止在单个功能内另造系统风格控件。

验收：2026-10-28，使用 Electron 35、实际主程序 HTML／CSS 验证 AI 排版范围和运行方式菜单，覆盖键盘选择、Esc 取消、Tab 离开、模态框内选择、动态选项、禁用与 1150×760 窗口边界。测试使用独立隐藏窗口，不加载业务服务。
