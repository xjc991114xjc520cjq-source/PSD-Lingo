# 单个 EXE 安装更新

交付文件：PSD-Lingo-0.3.2-安装更新.exe。无需解压，双击即可。请先保存当前编辑的绑定项目。

程序先校验内置载荷，优先识别正在运行的 PSD Lingo，并将该版本的 runtime 在原路径更新。旧程序退出后才替换程序目录，然后启动新版并等候启动确认。原路径下的项目、文档、PSD 及用户授权数据不参与替换。旧 runtime 保存在 runtime.previous-日期-随机号，启动失败会恢复旧版并重启。旧程序未退出或文件占用不释放时会停止，保留原版。

若运行了不同路径的多个版本，请仅保留需要更新的版本运行，避免选错目录。没有运行实例时，优先使用上次此安装器记录的路径；首次安装到用户 LocalAppData/Programs/PSD Lingo 并创建桌面入口。旧便携版尚无安装记录时，应保持需要更新的版本运行后打开此 EXE，以便识别原路径。

单个 EXE 是安装与更新入口；Electron 运行依赖由安装器自动部署到本机，不需要用户另外下载或解压。现有云端签名更新通道仍保留。

构建：先 node build.cjs 和 node package-portable.cjs ../PSD-Lingo-0.3.2，再 node installer/build.cjs。安装器使用本机 Windows .NET Framework 4.x 编译器，输出完整运行时载荷、SHA-256 校验和 WinForms 进度窗。修改版本时同步 package.json 和 build.cjs 默认输出名。
