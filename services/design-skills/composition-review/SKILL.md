# 本地化稿件设计审阅

本技能将 atk-design-review 的逐层审阅方法收敛为跨品牌排版审阅流程。只继承信息层级、产品识别、文字关系、系列一致性及前后对照方法；不继承其特定品牌色、产品参数或营销风格。授权文案和原稿决定事实；技能不授予新增、隐藏或删除对象的权限。

## 审阅步骤

1. 先看同状态整页：指出产品主体、首要信息、次要信息和阅读顺序。以原稿和用户明确要求确定设计方向，不因为个人偏好重做风格。原稿的背景纹理或光效与字形相交不自动构成缺陷。
2. 按 groupShape、hierarchyRhythm、readingZone、opticalSpacing 四个维度审阅，使用下述依据。文字完整、未溢出、无重叠属于技术门槛，不能代替任何设计维度的依据。
3. 发现组内问题时，先比较两种确实不同的结构，再选择适合当前画面的方案。比较要涵盖相邻说明、产品留白及参数区的影响，不孤立优化一个标题。保持文案语义及编辑权限。
4. 修改后使用当前实际整页重新核验，只有必要时补局部图。每项证据写可见关系、阅读后果及修正方向，不能只给“协调”“清楚”等形容词。无法辨认或没有当前图用 uncertain；确认有缺陷用 revise。不可宣称未渲染的提案已通过。

## 四项评审依据

- **groupShape / 组合轮廓**：将副标题、主标题和说明当作一个阅读组。检查长短行、轮廓与视觉轴是否有意组织；副标题过长而主标题突兀折行时，比较主标题适度收小、组合分行、整体对齐等结构，不能靠极小字号、拉伸字形或删字凑行数。单行不是普遍目标。
- **hierarchyRhythm / 层级节奏**：检查主次字面的大小与重量、组内行距和组间距离；同级职责应协调，主次职责应能扫描区分。标题变动后联动说明起点，避免说明困在标题残余空隙。结合整套已确认页面检查系列一致性，无对应参考则不猜。
- **readingZone / 阅读区域**：看完整段落在底图上是否持续可读并有明确归属。能辨认单字不代表段落位置合适；产品遮挡、跨强干扰区、说明与标题断开等须指出实际后果。原稿沿用不证明优美，也不自动成为本次新增错误；按用户要求和实际加重情况决定修复范围。
- **opticalSpacing / 视觉留白**：以实际可见字形和组件重量观察。参数的数值、单位及标签组成完整块，再比较两块至中间分隔符的可见空隙和纵向关系；价格把现价、币种、标签及有依据的原价视为完整组件。字符框中心、几何对称或未碰线均不能证明视觉居中。原生字符框的大块空白不参与美感判断。不能移动分隔符时先比较合法文字的重组；仍不可行应如实报告。

## 通过标准与边界

四项分别返回 accept / revise / uncertain 和简短证据。技术检查通过且四项均 accept 才能批准；改得比上一版好不能豁免剩余缺陷。整页检查必须考虑组间影响，局部通过不能代表整页通过。缺少对应图案、内容或参考时跳过不确定比较，不能从其他案例搬用坐标、文案、字号或强制版式。

本技能是明确的评审方法，不是客观美感评分器。只对实际证据作结论；保留用户最终审美决定，不伪称第三方设计师或独立模型已审核。避免增加额外模型调用及重复发送同状态图像。

## SKU赠品阅读带

按本产品实际赠品数量选择布局，单赠品不沿用双赠品窄槽。用户参考为横排时，依次检查赠送标签、分隔线、名称与价值、小字、赠品图片的水平阅读关系及光学垂直对齐；文字与图片保留独立槽位，避免整体居中破坏两者和标签的位置关系。以导出的最终JPG检查真实字形、PNG可见轮廓、留白与下方价格区层级；工程文件技术检查不能代替视觉结论。名称、金额、坐标从当前批准数据及模板取得，不沿用学习案例的具体产品。参考缺失或角色不同不得强制该结构。
