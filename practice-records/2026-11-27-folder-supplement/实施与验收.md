# 文件夹引用与中途附件接续

## 需求及边界
用户反馈文件夹内容无法交给流程，中途补充卡住；进一步明确文件、文件夹无法拖入补充与问题回答框。修复必须随软件发布，保持当前任务、原需求、已完成结果；不操作客户原稿。

## 原因与实现
- list_folder 文档承诺返回 fileId，实际子项只有 id。注册、目录列表、恢复引用统一返回同一身份的 fileId，旧 id 继续有效。子目录仍按需读取，不递归搬运或上传源文件。
- 普通问题补充后的 reviewRequested 被下一回合提前清除，本机工具再次等待旧问题，形成阻塞。保留重新分析许可，仍需用户明确回答，不代替批准。
- 原来全弹窗统一处理拖入，无法区分补充框与问题框。共享拖入回传目标元素，按目标把附件及路径加入当前输入；在回答提交前不自动中断问题，不丢已输入文字。
- 失败/停止后的补充走原任务 followup，并提交新增附件，保留任务上下文。普通运行中追加附件、改输出位置时同步停止过期规划。

## 使用
直接将文件或文件夹拖到补充说明框或某个问题回答框。确认已添加提示后点击提交补充说明或提交全部回答。文件夹内子文件由当前助手按需读取。失败任务可使用“补充并继续此任务”。
