# PSD-Lingo 功能性问题与需求报告
## 多画布批量查找替换、嵌套文字编辑与一级预览联动

日期：2026-10-31  
核对版本：本机源码 package.json 为 0.3.28。  
报告性质：需求分析及开发验收依据。本次进行了静态源码核对，未修改软件功能，未运行 Photoshop / Illustrator 原生文档测试。

## 1. 需求目标

用户需要在 PSD / PSB 和 Illustrator AI 文件中，以某一画布的文字为样本，批量修改其他画布的对应文案。对应关系既可能来自相同文字，也可能来自相同版面位置。

完整目标流程：

**选择画面中的文字或输入查找内容 → 手动输入新文案 → 先替换当前画布并预览 → 自动查找其他画布的对应文字 → 用户选择部分或全部应用 → 统一检查预览 → 明确执行导出。**

整个编辑阶段只更新项目状态与预览，保留源文件。文字即使位于多层智能对象或可解析的置入文件内，也应由软件定位、修改并回传到外层。软件界面始终展示一级详情页／原文档画板，用户无需进入子文档逐层编辑。

本文中“AI 文件”专指 Adobe Illustrator 的 .ai 文件，不指生成式 AI 功能。本功能的查找和替换不应依赖模型登录或联网服务。

## 2. 需求范围与术语

| 概念 | 定义及要求 |
| --- | --- |
| 画布／画板 | 默认指文档中的实际画板；多个导入文件也可按用户选择纳入同一批次。 |
| 一级详情页 | 原始文档对外展示的最终合成画面。子对象页面不能成为用户必须操作的工作界面。 |
| 无画板长图 | 作为一个画布处理；若要按“第几屏”匹配，应先建立并确认区域，不能擅自切屏。 |
| 文字块 | 可独立定位的原生文字对象。选择文字块与选择块内部分字符是两种不同操作。 |
| 深层文字 | 位于智能对象、嵌套子文档或可编辑置入内容中的真实文字对象。 |
| 原文件 | 导入的 PSD / PSB / AI 及其外部依赖。内部临时工作副本不等于原文件。 |

“全部替换”的推荐默认范围是当前文档的其他画布。跨多个文件、跨不同尺寸版式的批量应用应由用户主动扩大范围；这是本文建议的默认规则，尚需产品落地时确认。

## 5. 匹配与替换规则

### 5.1 将“怎么找”与“怎么改”分开

| 匹配方式 | 场景 | 判定规则 |
| --- | --- | --- |
| 相同文字 | 多画布都有“限时优惠” | 按文字内容搜索，不要求位置一致。 |
| 相同位置／对应文案块 | 每个画板右上角都是活动标题，但原文不同 | 以样本所在画板内的相对位置及文案块几何关系寻找候选，不要求文字相同。 |
| 相同文字且位置对应 | 同一画布中多次出现同词，只改指定模块 | 同时满足内容与位置条件，减少误选。 |

| 替换方式 | 示例 | 结果 |
| --- | --- | --- |
| 仅替换命中片段 | 查找“1000Hz”，输入“8000Hz” | “支持1000Hz回报率”变成“支持8000Hz回报率”，保留其他内容。 |
| 替换整个文字块 | 选中活动标题，输入“新品上市” | 将目标文字块内容整体替换为“新品上市”。 |

同一块中命中多次时，应标明次数，并提供“本次命中／该块全部命中”。位置匹配默认用于整块替换；如选择片段替换，则候选内还必须存在查找字符串。

### 5.2 文字匹配

默认按完整字符串精确查找，包括原有标点和空格；不默认进行模糊、语义或正则匹配。可选提供忽略英文大小写、统一换行符、忽略首尾空格，但每项须明确启用，不能静默合并本来不同的文案。

查找应基于试改前的样本文字快照。不能在当前画布改成新文案后，用新文案继续搜索其他画布。结果列表同时保留原文、当前预览文案和本次拟替换文案，防止覆盖已有手动修改。

### 5.3 位置匹配

位置须相对于各自画板计算，不能直接比较整个多画板大图上的绝对 X / Y。候选判断应结合相对中心、宽高、对齐锚点和所在版面区域；位置容差可调。

同尺寸同模板画板可直接匹配；尺寸不同但比例一致时，按相对坐标产生候选。横竖版差异较大、版式结构不同或同区域出现多个文字块时，应列为待确认，不能仅凭“最近的一块文字”自动批量选中。

内层文字必须先映射到一级画面，再参与位置匹配。不能拿智能对象内部坐标直接与其他画板坐标比较。

## 6. 建议的用户操作流程

1. 导入文档，展示一级画面及画板列表；后台扫描普通文字与可解析的嵌套文字，显示解析进度。
2. 在一级画面点击文字，或输入查找内容。若选择的是内层文字，可在侧栏显示来源路径，不切换画面。
3. 选择匹配方式与替换方式，手动输入目标文案。推荐入口名称为“批量查找替换”。
4. 点击“替换当前画布”，先查看本画布效果。若是输入查找且当前画布有多个命中，先定位并选择试改对象。
5. 试改后自动搜索其他画布的对应内容，并展示结果；不自动应用到其他画布。
6. 逐项勾选，或点击“选择全部可处理项”；再点击“应用到所选”。
7. 一级画面更新，显示完成、跳过和失败的数量；支持撤销本次批量应用。
8. 用户确认最终预览后执行“导出修改副本”，保留可编辑文件结构。

候选列表至少展示：文件名、画板名、外层定位缩略图、原文、替换后文字、命中依据、内层来源、共享影响、已有编辑冲突及可处理状态。

统计必须区分画布数、可见实例数、实际文字对象数和字符串命中次数。例如“涉及 8 个画布、10 个可见实例、6 个独立文字对象”，不能全部笼统称为“10 处修改”。

## 7. 深度解析与一级预览互通

### 7.1 PSD / PSB 智能对象

需支持嵌入式和链接式智能对象，以及对象内部继续嵌套对象的情况。解析时记录对象真实来源、稳定身份、嵌套路径、文字对象及所有外层实例。

普通分组递归不能替代智能对象解析。应由适配该内容格式的原生引擎读取：PSD / PSB 内容交给 Photoshop，AI 内容交给 Illustrator；其他格式须明确支持状态。Adobe 官方说明智能对象内容会按格式在相应应用中打开，保存后更新外层实例。[1]

解析遇到缺失链接、循环依赖、密码／权限限制、不可用原生引擎、过深嵌套或资源限制时，应说明停在何处，保留其他可用结果。扫描未完成不能显示为“已找到全部文字”。

### 7.2 Illustrator 的对应范围

AI 文件应分别处理普通分组与剪切组中的原生文字、符号实例中的可编辑内容，以及可解析的链接／嵌入置入内容，不能统一假设为 Photoshop 智能对象。

置入内容是否包含可编辑文字，取决于实际来源格式与对象结构。链接缺失需先重新定位；栅格图像或已转曲的文字不能直接视为可编辑 textFrame。Illustrator 的 Links 面板将链接、嵌入与 Edit Original 作为不同操作，软件亦应保留这些区别。[3]

### 7.3 一级画面上的选择与刷新

需要建立以下双向关系：

**一级画板上的可见文字位置 ↔ 外层对象实例 ↔ 逐层嵌套路径 ↔ 内层真实文字对象。**

点击命中要考虑层叠、遮挡、剪切和蒙版；同点重叠多个对象时允许切换候选。被完全隐藏或裁切掉的文字不应表现为一级画面中的可点击文字。

预览更新必须沿子对象到父对象逐层刷新。透视、旋转、变形或特殊混合效果不能靠简单矩形偏移保证正确；这类内容应使用原生工作副本合成。Adobe 明确说明，嵌套在其他智能对象内的链接文件不会自动更新，因此软件需要主动维护整条刷新链路。[2]

如果预览暂时只能显示近似结果，应标明等待原生刷新；不能把一级画面上覆盖一层新文字当作已经修改内层文字。旧文字及其效果必须从正确的合成位置消除，相关遮挡与蒙版继续生效。

## 8. 共享对象的影响范围

这是“先只替换一个画布”能否成立的关键。

多个画布可能引用同一个内层内容源。修改该内容源可能同步影响多个实例；这些实例中还可能有未勾选的画布。

必须提供两种清晰的操作语义：

- **仅修改选中实例（推荐默认）：** 在项目工作副本中隔离本次修改涉及的共享对象及必要父级链路，使未选中的实例保留原内容。
- **同步修改共享实例：** 列出所有受影响实例，用户明确选择后统一修改共同内容源。

单画布试改同样需要隔离，不能等到正式导出时再处理。若暂不能正确隔离，应阻止单实例应用并解释影响范围，而不是悄悄连带修改其他画布。

软件还需按实际文字对象去重，避免同一共享对象被重复执行替换。不同实例指定不同目标文案时，应先拆分依赖或提示冲突。

## 9. 预览、项目保存与正式导出

### 9.1 编辑期间

原始文档与外部链接文件保持不变。允许软件在独立工作目录中创建、保存临时副本，以获得真实原生合成结果。外部链接须在工作副本中重定向到副本，避免保存子对象时意外改到真实外部素材。

项目保存应包含替换操作、原文快照、来源身份与指纹、画板归属、共享关系及临时依赖的可恢复信息。重新打开项目后，应恢复已确认的一级预览；不能只保存屏幕截图，导致无法继续编辑或导出。

后台刷新结果应绑定当前项目版本；连续替换、撤销或切换文件后，旧任务不能覆盖较新的预览。

### 9.2 正式导出

导出以用户确认的预览状态为依据，按内层到外层的依赖顺序写入修改副本。保留应保留的文字可编辑性、画板、分组、遮罩、变换和实例关系。

链接素材应随输出打包并正确重定向，或按用户选择嵌入；输出不能依赖会被清理的临时路径。导出后在对应原生应用中重新打开，检查一级效果及深层文字内容。

预览或导出失败时列出具体对象，不能将失败项标为成功。批量文件允许逐文件报告结果，但单个输出文件应完整成功后才作为正式结果交付；导出前再次核对源文件是否被外部修改。

## 10. 编辑细节与异常处理

- 替换优先继承目标块自身的字体、字号、颜色、段落及对齐，不能把样本画布的样式强制复制到全部目标。
- 片段替换保留未命中字符及其样式；混合样式区间须做真实映射，不支持时列明原因。
- 替换后字数变长，应检测溢出、裁切、换行及重叠。是否自动缩小字号／调整行距由明确设置控制，不默认改变所有块的排版。
- 隐藏和锁定对象默认不自动应用；可按筛选项发现并显示原因。临时解锁或改变可见性后应恢复原状态。
- 已有手动编辑的对象标记冲突，默认不覆盖；用户可查看差异后决定。
- 文案已转曲或栅格化时，显示“未检测到可编辑文字”，不要把 OCR 识别结果冒充可编辑原生文字。OCR 重建属于另外的功能范围。
- “替换当前画布”与“应用到所选”分别形成一次可撤销操作；批量撤销应一并恢复文字、共享隔离关系和一级预览。取消候选勾选不撤销已完成的单画布试改。

## 11. 验收用例

| 编号 | 场景 | 验收结果 |
| --- | --- | --- |
| A01 | 10 个画板有相同独立文字块 | 先改当前一个；其余 9 个仅成为候选，确认后才应用。 |
| A02 | 不同句子中都包含“1000Hz” | 片段替换为“8000Hz”，其他字符保持原样。 |
| A03 | 同一块中有两次查找词 | 显示两次命中，可按本次／块内全部应用，无重复替换。 |
| A04 | 各画板相同位置原文不同 | 位置模式能列出对应文案块，替换后内容相同。 |
| A05 | 同一个词在画板上出现于不同位置 | 内容加位置模式只选中对应区域，其他位置不被误改。 |
| A06 | 不同尺寸、横竖版及同区域多个候选 | 正确使用画板局部坐标，歧义项等待选择。 |
| A07 | 两层以上嵌套智能对象内有文字 | 一级画面可定位并修改；外层刷新与导出后重开一致。 |
| A08 | 多画板共用同一个智能对象 | 单画布试改及勾选部分替换均不影响未选实例；同步模式明确展示影响范围。 |
| A09 | 链接智能对象的子层还链接外部文件 | 逐层刷新成功；原始 PSD / AI 及所有源依赖哈希不变。 |
| A10 | PSD 内置入 AI，或 AI 内有可编辑置入文档 | 调用正确的原生引擎；无法编辑的对象明确标示，其他结果仍可使用。 |
| A11 | AI 分组、剪切组、符号实例 | 可编辑内容正确定位；共享符号隔离／同步规则与选择范围一致。 |
| A12 | 旋转、缩放、透视、蒙版及层效果 | 点击位置与一级效果正确，修改后不残留旧字、不破坏遮挡。 |
| A13 | 长文案、缺失字体、混合样式及隐藏锁定 | 明确显示异常及处理状态，不静默丢样式或漏字。 |
| A14 | 已有编辑与连续两次批量操作 | 不自动覆盖旧编辑；逐次撤销准确，过期后台结果不能回写。 |
| A15 | 保存项目、关闭后重开并导出 | 一级预览、内层绑定、勾选范围及实际输出一致，依赖可找到。 |
| A16 | 缺失链接、循环依赖、解析取消或部分失败 | 不挂死、不损坏源文件，未解析范围和失败项明确可见。 |
| A17 | 导出 PSD / PSB / AI 后原生重开 | 外层画面与确认预览一致，支持范围内的内层文字仍可编辑。 |

验收须使用任务创建的测试文档和可核对的参考结果；不能直接拿用户正在编辑的原生文档试运行。性能测试应记录画板数、文字对象数、嵌套深度、源文件大小、首次扫描耗时和增量预览耗时，再确定可承诺指标。

## 12. 建议实施顺序与完成标准

| 阶段 | 交付内容 | 完成判据 |
