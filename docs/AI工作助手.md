# AI 工作助手

在左侧点击 **AI 工作助手**，或在文案工作台顶部点击 **交给 AI 工作**。助手只使用本机 Codex，沿用其登录及用户所选模型。模型获取、任务分析、内部文案对应、排版与复审均不会走软件 API 通道；连接失败保留任务并报错。一般文案对应功能的 API 设置独立保留。

## 开始任务

1. 点击“添加文件”或“添加文件夹”，也可把文件和文件夹一起拖入助手窗口。添加时仅引用本机路径，不复制或打包上传原稿/目录；点击开始后把路径与需求交给本机 Codex，按需列出目录、读取文案、调用软件导入原稿。可以使用当前工作区，未导入原稿时也能先分析附件。
2. 选择输出位置。导出时会在其中创建本任务的新文件夹，不覆盖源稿。
3. 等待模型列表自动获取，选择或手动输入模型；也可沿用当前设置。获取失败会提示原因，仍可手动填写。任务开始后模型固定，后续对话沿用它；切换连接或模型请新建任务。
4. 描述需求，也可使用“海报转语言”“仅分析”“视觉排版”通用提示。点击“分析并开始工作”。

任务会读取原始需求、完整历史、用户回答及中途补充，然后逐步调用软件。附件中的文字只作为资料，不能自行变成执行授权。

## 接管期间

蒙版中央显示当前状态、步骤、Logo 动画和进度。需要查看原需求、工具反馈与附件时，点击顶部“查看对话与附件”。顶部可以继续添加文件、文件夹及选择输出位置。

- **暂停工作**：立即中止当前分析请求。原生导入或保存已开始时，等待该操作结束后暂停，不强制杀死 Adobe。
- **继续工作**：沿用原始任务和已经完成的结果，不从头重复写入。
- **终止工作**：停止规划下一步；原生保存已经开始时等待安全边界，已产生的副本保留。终止不等于撤销已经执行的操作。
- **提交补充说明**：后台明确附带“这是同一原任务的中途补充”的标记，保留原需求、已完成操作、回答及未解决事项。提供“补充约束”“调整优先级”“纠正理解”三个通用开头。尚未应用的过期分析提案不会执行；已执行的原生操作会先记录真实结果。
- **回答问题**：所有问题都显示在中央区域，多项时可在问题区域滚动查看，支持选项和自由填写。全部回答后一次提交；进度刷新不会清空尚未提交的回答。

分析服务没有提供百分比时，进度条显示等待，不虚构完成比例。文字排版等功能返回实际项目数时，显示当前项目进度。

## 已接入的能力与边界

| 能力 | 行为 |
| --- | --- |
| 当前项目 | 分页读取原稿、可编辑文字、绑定与文案记录 |
| 文件夹 | 仅引用路径；按需分页列出一层内容，再继续子目录或选择文件读取/导入；不一次递归读取整目录 |
| 附件读取 | TXT、CSV、TSV、JSON、DOCX；XLSX 工作表、行列和图片锚点；PNG/JPEG/WebP 参考图 |
| 原稿导入 | 使用软件原有 PSD/PSB/AI 导入流程，大型原稿不作为文本整体发送给 AI |
| 文案导入与对应 | 使用完整目标文案；XLSX 显式指定工作表、行列范围；保留现有绑定，替换已有文案前确认 |
| 文案合并与改字 | 将多条完整译文合并到一个现有文字对象；依据已确认要求修订已绑定文字的时间、币种等，保留导入文案原记录并支持撤销；不会新建或删除原生对象 |
| 视觉排版 | 调用软件现有排版服务与最新通用学习库，结合真实预览；绑定和排版修改进入撤销历史 |
| 副本导出 | 自动逐画板审阅文案覆盖、重复消息、标题层级、合理行数、光学平衡及边框/线条留白；存在失败或不确定项时保留待修副本与清单，不能标作全部完成；原生重开与用户视觉批准仍分别核验 |

首版尚未把多图改字、字体安装、批量多语言方案和任意 Photoshop/Illustrator 操作开放为助手工具。这些功能原来的手动入口仍可使用。AI 必须说明尚未接入的步骤，不能声称已经调用。

当前不支持直接附加 PDF、压缩包或任意脚本。参考图每张不超过 8 MB，任务附件最多 24 份。文档正文有读取上限；表格可分页读取，不会默默截掉内容后宣称已完整分析。

绑定文案后的预览与排版会等待当前译文画面生成，工作台隐藏时也会加载，不再依赖先打开工作台。生成失败会保留原生错误，不能把原稿图作为当前效果继续排版。确认原生程序恢复可用后，助手可用 `preview` 的 `retry:true` 重建只读预览；不会自动反复尝试导出写入。

## 继续、记录与验收

任务结束后，在输入框描述后续需求并点击“继续此任务”，将保留前面的对话和成果。做无关工作时点击“新建独立任务”。

任务日志保存在软件用户目录下的 `agent-tasks`，仅保存需求、文件信息、操作反馈与回答；供本次视觉分析使用的小型预览在 `agent-context`。不把源稿二进制写入日志或云端学习库。当前支持软件会话内暂停续做，关闭软件后不会自动恢复执行；已有日志可供排查，不代表重启后的自动续做。

软件操作长时间没有返回、无法判断是否已执行时，会停止任务并要求检查结果，不自动盲目重试。最后仍需查看改后预览及 Adobe 导出画面，不能仅凭文字框尺寸或数值检查判定美观。

Illustrator调用按顺序执行并在提交文件脚本前检查接口。若提示“文件脚本尚未提交”，先结束正在编辑的操作及模态弹窗；仍失败时保存工作后重启Illustrator，再继续任务。若提示“脚本已提交，执行结果不确定”，先检查输出目录中的副本；软件保留可能已保存的文件并停止后续步骤，不能直接重复导出。软件不会自行关闭用户文档或重启Adobe。

本机 Codex 的深度分析不再受助手旧有三分钟分析超时中断，可随时暂停或终止。软件写入仍受原生状态保护；模型名称相同不意味着输入上下文、工具与执行环境相同，也不保证不同运行给出完全一样的设计。

人工参考图片在当前任务内按文件身份保留，后续预览不会覆盖它。助手调用排版时须明确选择已读取、图案和内容匹配的参考图；内部规划、候选复审和整页审阅复用这些参考，未知页面跳过。工作区修改后清除旧的当前效果图，重新预览后才能作为新效果使用。参考缓存有上限，被移出的图片按需重新读取，不把整套大文件装入学习库。
# 重复文案的隐藏与恢复（本地候选，原生验收待完成）

AI文件可通过助手列出文字及小范围纯矢量候选，查看原图与隐藏后的局部对照，再隐藏已确认重复的对象。候选身份不代表它一定是文字：品牌、产品、装饰和含图片的混合组不能按重复文案自动处理。

隐藏保留对象，可用Ctrl+Z撤回或让助手恢复；项目保存会保留隐藏状态。隐藏后必须检查所在画板的当前预览，导出另存副本后仍需原生重开检查。本功能不等于改写转曲文字，不支持在图片中擦除文字。

开始新任务或续做前必须选择输出文件夹。输出文件夹不存在或不可写时，任务不会启动，不会先调用模型再等待补选。

## 会话与重复工作的优化（0.3.58）

同一任务使用同一本机Codex会话持续分析，只追加新事件及变化的图片；完整对话仍保存在本机。中途补充、回答和未解决错误继续有效；模型、连接环境变更或中断后会重新提供完整上下文，不以摘要替代早期要求。软件重启后仍不会自动执行旧任务。

相同稿件状态、需求、模型、参考及学习规则下，可复用已经完成的排版或整页复审。失败的审阅仍然失败；明确提出新的修复依据会重新规划，要求重新复核也可强制审阅。稿件修改或学习文件更新后缓存失效。导出另有原稿与输出哈希验证，只有同一任务的同一成功成果才复用；不确定原生操作不会自动重试。

接管状态下显示请求与用量，包含主助手及内部匹配、排版和复审。输入总量包含缓存输入，不能将两者相加。部分失败请求没有返回用量，会明确标注，统计不等于账单费用。减少重复传输不代表模型不再处理历史，也不保证任意任务有固定速度提升。

学习规则使用本机最新已验证文件，云端定时同步在后台进行，网络等待不阻塞当前排版。同步到的新规则在后续步骤读取并使相关缓存失效。
