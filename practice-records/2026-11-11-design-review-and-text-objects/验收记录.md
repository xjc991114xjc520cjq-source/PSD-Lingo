## 实现

- 新增原生文字合同及 create_text、set_text_presence；AI 受限图案工具增加 clear 模式。先验证完整来源再改变；捕获原生对象引用避免移除导致索引错位；在副本执行。
- 全层数组支持对象新增撤销，排除 transformSelected，保留当前选择；项目/语言模板能恢复新增文字、源文字隐藏/清除。
- 内置第三方固定提交和许可，4份方法逐份提供适用范围及证据，基础2份不得跳过；图像经当前本机 Codex 的 AnalysisExchange 交回同一会话，不另开 API 或 SDK 推理。
- 审验 repairPlan 合并不同方法意见：可见问题、结构根因、对象、联合动作、验收标准、依赖。遗漏失败项、伪造对象和依赖循环拒绝。整页诊断会自动交给同状态后续规划；内部候选复审意见传入下一轮。
- 已否决相同提案在再次渲染前停止；相同无进展状态不能靠 replan 重跑。明确失败直接修改，不重复补整页审验；仅 uncertain 提供同状态细节。保留最终实际图核验。
- 流程学习规则 revision8，8806字节；仅通用角色及流程，不含客户源文件、完整文案、截图或样本坐标。
