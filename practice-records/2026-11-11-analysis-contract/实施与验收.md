## 通用实现

1. 所有软件工具结果按 UTF-8 大小判断：超过 24000 字节，通过当前 thread/turn 的原生 turn/steer 完整交付文本，与新图像合并同一次传输；工具输出只留短回执。排版、读表、工作区都覆盖，不加新模型、不改 API、不重开任务。24000 是保守传输边界，不是视觉或文件大小限制。
2. 完整资料明确标注为软件结果，非用户中途补充，不扩张编辑授权。图像仍按内容摘要复用，技能仍按完整内容身份复用；资料先成功交付才返回回执，传输失败不能伪称已收到。
3. 首次交接提供紧凑 outputShape；实际 JSON Schema 不删减。新增预检覆盖当前分析协议使用的对象/数组/必填/额外字段/枚举/联合类型/数值及长度边界，最多 80 条字段诊断；不是通用 JSON Schema 引擎。之后仍执行原有语义、身份、文案、字体、参数和视觉解析器。
4. 一次纠错列清字段路径、规则和期望类型，同一 analysisId 修复完整回答，保留渲染与原操作。不能自动补组、编造结构方案、篡改文案或把 revise 改 accept。仍最多三次，失败闭锁。
5. 结构方案分清格式、组身份/遗漏、索引、重复结构及空白依据；格式缺项先报告，再做组关联，避免误报设计不足。复审与整页审计共用分析预检。
6. 历史记录保留每次校验明细及末次失败原因。结束 exchange 释放旧门禁，但原工具失败历史保留，不得把失败任务自动标完成。
