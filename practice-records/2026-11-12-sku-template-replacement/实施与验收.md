# SKU 外部底部模板替换：软件开发记录

日期：2026-11-12。基线：正式 0.3.69 / `24d038f`。本次为未发布的本地开发增量。

## 要求和执行边界

客户测试分支反馈 0.3.69 只能逐产品改既有文字，缺少外部 PSB 底部块替换、优惠子区删除与整体布局合同。新增软件通用能力，而非为单份客户稿另写代做脚本。

业务参考输入：用户指定的 I 盘键盘 PSB、Downloads 的返场模板 PSB 和产品 XLSX。详细路径见测试分支原交接记录；新原稿约 2.36 GB，不沿用旧 Downloads 原稿的产品身份确认。本轮未读取客户源稿、未新增源稿哈希、未运行客户修改任务。先前只读模板检查属于上轮记录，不算本轮原生验收。

用户最新指令：暂停测试，随后要求“开发”。本轮不调用 Adobe、不使用 computer-use、不启动客户实机测试、不自动唤醒续测。用户关闭 Windows 应用保护后明确要求重试，范围为先前失败的安装器／更新器 Windows 子进程检查。

## 软件实现

- `sku-template-plan.cjs`：声明式替换合同。原生旧块对象、模板参照框、逐产品逐字段价格、删除对象和视觉锚点一次配置；校验角色、原文、样式分段和字符完整覆盖，排除／空白字段必须移除示例金额。全部采用画板覆盖，跳过画板保持。
- `sku-template-native.cjs`：只读结构扫描；独立复制模板；原生画板内对象转换为普通分组导入；明确删除旧块、清理子区、改字和位置执行；独立嵌入智能对象；保存重开验证子树可编辑文字、样式和位置。不将原已越界的装饰当作新增裁切。不关闭已存在的子文档；遇其未保存状态停止。
- `services/sku-product-template-engine.cjs`：助手／后台共用服务；结构 JSON 和小尺寸模板参考图缓存，复用扫描不重开 Adobe。源稿、模板、批准及字段变化时失效；主进程从持久扫描重新编译计划，拒绝 renderer 篡改执行动作。源稿只深入采用画板；结果分页，不反复发送完整字符描述符。
- 助手新增 `inspect_product_template`、`configure_product_template`，模板必须来自当前任务附件；计划可撤销并进入现有工作记录／项目保存链。模板参考图明确标记为外部参考，不当作当前成果。
- 复用正式画板保存、重开、全部 JPG 和导出缓存；最终多技能审验得到逐板价格来源、字段排除及清理对象，检查真实整页图面。原生结构核验不替代设计验收。
- `services/sku-template-background.cjs` 为正式无窗口调用入口，共用服务；不包含客户专用路径或执行脚本。后台返回“尚未视觉验收”，不能直接冒充客户成稿通过。

## 验证及失败记录

新增 11 项自动用例（10 项模板＋1 项助手附件／IPC），覆盖跨产品／跳过画板／误删产品拒绝、字段漏改、示例价清除、混合样式、等比布局、持久缓存重启／篡改／文件变化、原生脚本语法、画板身份继承、旧装饰越界、撤销事务／过期任务、最终设计审验资料传递。原生函数的结构模拟和脚本语法检查不等于 Adobe 实机通过。

首轮全量 785 项中 780 通过，5 项 Windows 安装器／更新器／图标工具检查因 `spawn UNKNOWN` 等启动错误失败。用户关闭 Windows 应用保护后，相关 8 项重试全部通过；补齐最终审验合同用例后的最终全量 **786 项通过、0 失败**。

证据位于本工作树忽略目录 `work/sku-template-development/`：`first-regression.log`、`windows-retry.log`、`final-regression.log`、`build.log`。记录测试中修正的开发缺陷：对象扫描漏继承画板身份、模板分组误读文字属性、旧装饰越界误拦截、生成脚本分支语法及审验夹具语法；对应回归已覆盖或经最终脚本编译通过。

Renderer 与本地可运行开发包构建成功。位置：本工作树 `work/sku-template-development/local-build/runtime/PSD Lingo.exe`。仅构建，未启动、未安装、未签名发布；版本基线仍为 0.3.69，不能与正式新版混淆。
