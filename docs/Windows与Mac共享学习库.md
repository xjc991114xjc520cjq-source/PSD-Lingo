# Windows 与 Mac 共享学习库

两端连接同一个生产云端通用规则库，不需要共享磁盘或手动复制文件。Mac 0.3.114 内置通用库 revision 17，并沿用与 Windows 相同的自动同步协议和签名公钥。

- 软件启动并取得有效授权后立即尝试同步，此后每 5 分钟检查一次；重新激活授权时也会尝试同步。
- 按规则库 ID 和 revision 合并：较新的规则自动同步，同版本内容冲突会保留本地文件并提示，不静默覆盖。
- 下载结果经过签名、设备身份和内容摘要校验，再原子写入本机缓存。离线仍可使用内置及此前验证的规则，联网后重试。
- 同步成功后的后续任务／排版读取更新后的适用规则；不会重放已经执行的修改，也不会自动重做已完成项目。
- 此通道共享经过结构校验的通用规则 JSON。客户 PSD、AI、截图、草稿及工程目录不由此通道扫描或上传。历史案例参考使用另一条已有通道，不等于共享整个本地工作目录。

生产验证（2026-11-27）：实际 Mac 通过应用使用的 Electron 网络及钥匙串设备签名完成授权、发布／同步和云端签名快照校验，云端与本机通用库均为 revision 17，摘要一致。双设备新增、更新和撤回另由真实 Worker SQL 及签名集成测试验证。同步失败不会阻塞编辑或导出。
